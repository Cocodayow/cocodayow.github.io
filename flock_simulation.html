Flocking Simulation

GPU-accelerated boids with character behaviors — large-scale agents with obstacle avoidance, target following, and smooth group motion.

About the project

A real-time flocking system combining GPU-accelerated Boids (separation, cohesion, alignment) with character behaviors such as seek, flee, arrival, wander, obstacle avoidance, and leader following. Optimized spatial partitioning keeps neighbor search fast at scale.

Key features

  • GPU Boids: separation, cohesion, alignment
  • Spatial partitioning for large-scale neighbor search
  • Character behaviors: seek, flee, arrival, wander, avoidance
  • Leader following + group motion
  • Unity plugin integration for live parameter tuning
