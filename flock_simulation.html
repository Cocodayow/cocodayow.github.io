Real-Time Flocking Simulation and Character Behavior System

A real-time flocking simulation system that combines GPU-accelerated Boids behavior with character movement control to simulate large-scale agents, obstacle avoidance, target following, and smooth group motion.

Key Features

  • GPU-accelerated Boids simulation with separation, cohesion, and alignment behaviors
  • Optimized spatial partitioning and neighbor search for large-scale agent simulation
  • Character behaviors including seeking, fleeing, arrival, wandering, obstacle avoidance, and leader following
  • Unity Plugin integration for real-time visualization and parameter debugging
