Solar Wind Visualization System

An interactive Unreal Engine 5 visualization system for solar wind and space weather data, using voxel-based rendering and VDB processing to support real-time exploration of coronal mass ejection simulation results.

Key Features

  • Converted orbital and simulation data into high-resolution VDB voxel meshes for 3D visualization
  • Integrated voxel slicing, color scale control, and visibility adjustment tools in UE5
  • Implemented VR controller-based interaction for floating UI panels and visualization parameter control
  • Supported real-time playback, adjustable playback speed, and interactive inspection of space weather data
