Solar Wind

An Unreal Engine 5 visualization of solar wind and space weather, with voxel-based VDB rendering and VR interaction.

About the project

An interactive UE5 visualization system for solar wind and space weather simulation data. Orbital and simulation data are converted into high-resolution VDB voxel meshes for 3D exploration, with voxel slicing, color scale, and visibility controls. Includes VR controller-based interaction for floating UI panels and visualization parameter control.

Key features

  • Converted orbital data into VDB voxel meshes
  • Voxel slicing, color scale, visibility controls
  • VR controller interaction with floating UI panels
  • Real-time playback + speed adjustment
