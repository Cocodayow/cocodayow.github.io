MPM Material Simulation

A Houdini plugin that uses the Material Point Method to simulate snow, sand, and elastic objects with mesh colliders.

About the project

A real-time Material Point Method plugin for Houdini that converts input meshes into particles and simulates deformable materials. Supports mesh colliders, user-defined simulation domains, and a wide range of material parameters including Young's modulus, Poisson's ratio, and substeps.

Key features

  • MPM simulation for snow, sand, and jelly-like materials
  • Custom input meshes, mesh colliders, bounding-box domains
  • Reset simulation, timescale, emitter, substeps controls
  • Grid resolution, gravity, mass, Young's modulus, Poisson's ratio
