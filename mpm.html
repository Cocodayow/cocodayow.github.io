MPM-Based Material Simulation Plugin

An MPM-based material simulation plugin that converts input meshes into particles and simulates deformable materials such as snow, sand, and elastic objects with mesh colliders and user-defined simulation domains.

Key Features

  • Material Point Method simulation for snow, sand, and jelly-like materials
  • Supports custom input meshes, mesh colliders, and bounding-box simulation domains
  • Plugin style workflow with reset simulation, adjustable timescale, emitter, substeps, grid resolution, gravity, mass, young's modulus, poisson's ratio
