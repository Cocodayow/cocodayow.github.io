About the project

A 2D roguelike platformer built in Godot. Features turn-based combat with enemy encounters, a character recruitment system for building a playable team, and level-based progression. Covers full level design, player movement, collision, and combat interaction.

Key features

  • 2D platformer gameplay with roguelike progression
  • Turn-based combat with enemy encounters
  • Character recruitment system
  • Level design, movement, collision, combat
