Wrath of Zeus

A real-time 3v1 asymmetric multiplayer game built on a custom C++ and OpenGL game engine, featuring procedural maze generation, dynamic lighting, skeletal animation, and player interaction systems.

Key Features

  • Custom C++ game engine with OpenGL rendering pipeline
  • 3v1 asymmetric gameplay where players escape while Zeus controls threats from above
  • Procedural maze generation using room templates, entrance matching, and frontier expansion
  • Skeletal animation system using Assimp-loaded bones, keyframes, and hierarchical FK transforms
  • Dynamic lighting and shader rendering for real-time visual feedback
  • Multiplayer interaction systems for player movement, traps, and game-state updates
