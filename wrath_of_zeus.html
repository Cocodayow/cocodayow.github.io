Wrath of Zeus

A 3v1 asymmetric multiplayer game on a custom C++ engine, with procedural mazes, dynamic lighting, and skeletal animation.

About the project

A real-time 3v1 asymmetric multiplayer game where players try to escape while Zeus controls threats from above. Built on a custom C++ / OpenGL game engine with procedural maze generation, dynamic lighting, skeletal animation via Assimp, and full multiplayer interaction systems.

Key features

  • Custom C++ engine with OpenGL rendering pipeline
  • 3v1 asymmetric gameplay (escapees vs. Zeus)
  • Procedural maze via room templates + frontier expansion
  • Skeletal animation with Assimp-loaded bones + keyframes
  • Dynamic lighting and shader-based visual feedback
  • Multiplayer movement, traps, and game-state updates
