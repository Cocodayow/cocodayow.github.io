Mini Minecraft

A Minecraft-inspired voxel terrain engine with chunk-based streaming, procedural biome generation, and real-time player physics.

About the project

Built from scratch in C++ and OpenGL, this project explores the core systems that make modern voxel games tick — chunk-based world streaming, procedural biome generation, multithreaded terrain and VBO generation, animated water and lava, distance fog, and a fully interactive player with placement, removal, inventory, crafting, rivers, caves, and bombs.

Key features

  • Chunk-based voxel terrain system
  • Procedural biomes: grass, desert, mountain, snow
  • Multithreaded terrain + VBO generation
  • Animated water / lava, distance fog, texture mapping
  • Player movement, collision, placement, removal
  • Inventory, crafting, rivers, caves, bombs
