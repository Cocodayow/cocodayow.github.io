Mini Minecraft

A Minecraft-inspired voxel terrain engine built with C++ and OpenGL. The project features procedural terrain generation, chunk-based world streaming, multithreaded terrain loading, player physics, block interaction, and real-time rendering.

Key Features

  • Chunk-based voxel terrain system
  • Procedural biome generation with grass, desert, mountain, and snow regions
  • Multithreaded terrain and VBO generation
  • Texture mapping, animated water/lava, and distance fog
  • Player movement, collision, block placement, and removal
  • Inventory, crafting, rivers, caves, and bombs
